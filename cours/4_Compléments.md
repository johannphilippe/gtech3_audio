# Compléments techniques optionnels 

## Quelques moteurs audio génériques 

1. RtAudio - API C++ - encapsulation des API des systèmes principaux 
2. MiniAudio - Pareil que RTAudio, mais header only library, et avec des fonctionnalités supplémentaires 

## Framework audio générique 

1. JUCE - Framework de développement Audio : standalone, plugins (etc). C'est le framework le plus utilisé dans le monde du developpement audio. 
2. WWise - Environnement de design audio pour le jeu vidéo : on peut créer des plugins
